# Git Skills

A small Git practice repository. Its current content is documentation rather than an application, making it suitable for learning repository history, branches, and collaboration.

## Requirements

Git.

## Getting started

```sh
git clone https://github.com/JingdaKang/gitskills.git
cd gitskills
git status
git log --oneline --all
```

## Project structure

| Path | Purpose |
| --- | --- |
| `README.md` | Repository overview |

## Configuration and limitations

Use a practice branch for exercises so the default branch remains a useful starting point.

## Development and validation

Inspect changes with `git diff` and history with `git log`; there is no application test suite.
